# Git Learning Journal - Day One

## What I Learned

- Configured my Git username and Botho University email address.
- Generated an SSH key and used it to authenticate with GitHub.
- Created a personal fork of the Docker Awesome Compose repository.
- Cloned my fork to my local computer using SSH.
- Added the original Docker repository as an upstream remote.
- Used `git fetch upstream` to retrieve information about branches in the original repository.
- Learned the difference between `origin` (my fork) and `upstream` (the original repository).

## Key Concepts

- A fork is my own copy of another GitHub repository.
- A remote is a reference to a repository hosted elsewhere.
- A branch allows me to work on changes separately from the main branch.
- SSH authentication allows Git to communicate securely with GitHub.

## Next Steps

Continue practising Git by creating commits, pushing branches, opening pull requests and learning safe ways to undo changes.
